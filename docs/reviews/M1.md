## Recommendation: **GO**

Gate criteria: E1, E2 and E3 each need ≥ 3 full loops, and E4 must prove no callback. Results:

- **E1** (Base ping): 5/5 full loops, plus a 1-sample smoke run.
- **E2** (Unichain ping): 5/5.
- **E3** (Base reference-pool swap): 6/6.
- **E4** (skip): 5/5 `Skipped` on Lasna. Each has zero `CallbackRequest` logs, no `Pinged` on Base and empty `getCallbacks`. An earlier E4 run of 5 had the same Lasna result, but its Base-side check failed on a watcher error.

**Full loop, origin block → Base callback block:** median **1.4 s** (E1), **1.4 s** (E2), **2.0 s** (E3); max 2.8 s (estimated sub-second).

**One platform problem, not blocking:** `getCallbacks` always returns `[]` (see Surprises, and the issue note at the end).

## Surprises / contradictions with plan.md and FACTS.md

1. **`getCallbacks` is always empty.** It returned `[]` for all 27 reactive txs in the result files, including the 17 relayed ones whose callbacks are confirmed on Base, and was still empty 10–35 min after delivery. The docs say records are written "after delivery". The system contract's `CallbackRequest` log in the Lasna receipt (topic0 `0xef94dbc611c4b95bf4b8ba34b413972180c2faf26fbb480befacedd83e07b133`) and `rnk_getCallBackLogs(block)` do show the request. Effect:
   - The watcher matches destination txs through our own indexed `Pinged(originTxHash)` event instead of `getCallbacks`.
   - E4's "no callback" proof rests on 0 `CallbackRequest` logs plus no `Pinged` on Base. Empty `getCallbacks` can't tell the two cases apart.
2. **Lasna block timestamps are behind real time.**
   - A Lasna reactive tx is stamped 1 s before to 1 s after its origin block (median −1 s for E1/E2), and always exactly 2 s before the Base callback block.
   - The Lasna RPC's `eth_getLogs` also lags: the Base callback is often visible before the Lasna log ("Lasna seen → dest seen" median −609 ms in E1).
   - So the per-hop split (origin→Lasna, Lasna→dest) can't be measured from timestamps or our polling. Only the total is reliable.
   - `latency.ts` in M4 should report total loop latency as the headline number and per-hop wall-clock only as a diagnostic.
3. **Reactive charges are lower than the formula.** For example, a Ping costs 0.0128474 lREACT vs `100 gwei × (88,289 + 100,000)` = 0.0188 predicted. Lasna receipts also show `effectiveGasPrice` 0 (the tx says 100 gwei), so receipts can't be used for cost and we use balance diffs instead.
4. **The loop is fast.** Origin block → callback block is median 1.4 s for pings and 2.0 s for swaps. The roughly 4–7 s users see on the wall clock is mostly origin inclusion and RPC polling.
5. **Base public RPC caps `eth_getLogs` at 200 blocks (≈ 40 s)** and errors if `toBlock` is past the head. The watcher now scans with a cursor in chunks.
6. Unichain public RPC sometimes returns "block not found" right after returning a receipt (load balancer). The watcher retries.
7. Plan §6 M1 text says `Ping(uint256 n, uint256 ts)`; the M1 brief's `Ping(uint256 indexed n, bool skip, uint256 timestamp)` was implemented instead.

## Decisions made + why

1. **One idempotent multi-chain script** (`M1Deploy.s.sol --multi`): one dry run shows the whole plan. Each step skips what already exists, and since the security fix it **reverts** instead of redeploying a recorded address (rule 7).
2. **PingOrigin also uses CREATE2,** so it has one address on both chains.
3. **tWETH salt mined:** `keccak256("hedgeline.TestToken.tWETH.v1.0")` (first suffix that works); tUSDC `keccak256("hedgeline.TestToken.tUSDC.v1")`. `contracts/script/MineTokenSalt.s.sol` reproduces it.
4. **`react()` decodes `skip` as uint256,** so a malformed bool can't revert.
5. **Lasna lookup by event:** `Relayed`/`Skipped` are indexed by `originTxHash`, so the watcher finds the Lasna tx with `eth_getLogs`.
6. **`Pinged.originTxHash` is indexed** so the dest tx can be found without `getCallbacks`.
7. **Callback gas limit 300k** for M1 (approved).
8. **`deployments.json` tx hashes** are filled by `scripts/record-broadcast.ts` from the forge broadcast file, never by hand.
